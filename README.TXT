# Memoria Viva 🧠✨

Plataforma web de estimulación cognitiva orientada al cuidado y bienestar de personas con Alzheimer, diseñada bajo estrictos criterios de accesibilidad, limpieza visual y usabilidad intuitiva.

## 🚀 Sobre el proyecto
Este proyecto nace con el firme objetivo de ofrecer herramientas digitales útiles, amigables y libres de distracciones para la estimulación mental. Prioriza los espacios amplios, paletas de colores suaves (tonos turquesa y pasteles) y tipografías de alta legibilidad para evitar la fatiga visual.

## 🛠️ Stack Tecnológico
* **HTML5** para la estructura semántica.
* **CSS3** (con Flexbox y diseño adaptativo/responsive) para una interfaz limpia, moderna y con microanimaciones fluidas.
* **JavaScript (Vanilla)** para la lógica interactiva de los juegos y la gestión dinámica de contenidos.
* **Control de versiones** con Git y GitHub.

## 📈 Evolución y Ampliación del Diseño Inicial
Durante el proceso de desarrollo, el proyecto ha crecido respecto al planteamiento inicial de diseño, incorporando nuevas experiencias interactivas y mejoras de usabilidad como la integración de efectos de aparición suave (fadeIn) en los paneles y transiciones sutiles de elevación (hover) en los botones táctiles e interactivos, ayudando a que el usuario comprenda claramente dónde pulsa sin cambios bruscos de pantalla.
Incorporación de soporte para guías en PDF organizadas en carpetas específicas y apertura controlada en pestañas nuevas mediante target="_blank" y atributos de seguridad, asegurando que el cuidador o familiar pueda consultar la documentación sin perder la sesión del juego.

Pantallas extras:
1. **Juego de Memoria (Tarjetas 3D):** Ejercicio dinámico de emparejamiento con efectos visuales limpios.
2. **Juego de Completar Palabras (Ampliación sobre el diseño original):** 
   - Motor dinámico basado en una base de datos interna de **100 palabras**.
   - Sistema de niveles de dificultad seleccionables y disposición horizontal natural de las letras.
